# Pandas Study

A repository dedicated to learning and practicing **Pandas**, one of the most important Python libraries for data analysis.

## Topics Covered

- Reading and writing CSV files
- DataFrame and Series
- Filtering data
- Missing values
- Creating and modifying columns
- Sorting
- GroupBy
- Aggregations
- Merge and Join
- Exploratory Data Analysis (EDA)
